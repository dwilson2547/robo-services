# adb: installing Android apps from this machine (WSL)

Moved to the workspace skill **`android-device`** (`meta/SKILLS/android-device/`), which
loads automatically for phone work and ships the `adb-phone` wrapper. It covers Windows
adb.exe over wireless debugging (WSL adb stays unauthorized), the pairing-port vs
connect-port rule, APK install, logcat, screenshots and taps.
